# Exercice : HTML

Pour cet exercice, vous devez produire un document HTML qui permet
d'afficher le contenu de [cette page]. Concentrez-vous sur la structure
de la page, et non sur son apparence. Votre balisage ne devrait pas
inclure de `<div>` ni de `<span>`.

[cette page]: https://vitrinelinguistique.oqlf.gouv.qc.ca/23692/lorthographe/accents-trema-et-cedille/accent-aigu-et-accent-grave/les-accents-fonctions-et-histoire
