# Exercice : Générateurs de sites statiques

Utilisez le [générateur de sites statiques] vu en classe pour créer un
petit portfolio présentant les projets de conception que vous avez
réalisés dans le programme jusqu'à présent.

Votre site doit inclure :

- une page d'accueil avec des liens vers les projets,
- une page de détail pour chaque projet, et
- une page à propos.

[générateur de sites statiques]: https://github.com/582-21W-MA/ssg
